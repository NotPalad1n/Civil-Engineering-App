# CivilTools 🏗️

## Description

**CivilTools** is a comprehensive, web-based platform providing simple and effective civil engineering calculation tools. Designed for students, technicians, and structural engineers, it allows users to calculate reinforcement sections for columns, beams, slabs, and footings with professional precision. The application currently complies with the **BAEL 91 mod 99** regulatory framework, with **Eurocode** integration planned for future updates.

🔗 **Live Application:** <https://civil-engineering-app.vercel.app/>

## ✨ Key Features

* **Reinforcement Calculations:** Accurately size reinforcements for concrete structures.

* **Standards Compliance:** Built strictly according to BAEL 91 mod 99 regulations.

* **Geotechnical Estimates:** Calculate mechanical parameters from in-situ soil tests.

* **Intuitive Interface:** A clean, fluid, and easy-to-use interface built for fast daily use.

* **Zero Installation:** 100% web-based—access your tools from any browser without downloading software.

## 🧰 Available Modules

### BAEL 91 mod 99 (Reinforced Concrete)

* **Solid Slab (*Dalle pleine*):** Reinforcement calculations for solid slabs.

* **RC Beam (*Poutre en béton armé*):** Reinforcement sizing for rectangular concrete beams.

* **RC Column (*Poteau en béton armé*):** Reinforcement calculations for concrete columns.

* **Centered Isolated Footing (*Semelle isolée centrée*):** Reinforcement and soil stress verification for isolated footings.

* **Centered Continuous Footing (*Semelle filante centrée*):** Reinforcement and soil stress verification for continuous footings.

### Geotechnical (*Géotechnique*)

* **Correlations:** Estimation of mechanical parameters based on standard in-situ geotechnical tests.

## 🔜 Upcoming Features

* **Eurocode Integration:** Full support for Eurocode standards across structural and reinforcement calculations.

## 🚀 Getting Started

If you are cloning this repository to run the app locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```

2. Navigate into the project directory:

   ```bash
   cd your-repo-name
   ```

3. Install the dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

### Running Locally

Start the development server:

```bash
npm run dev
# or
yarn dev
```

Open <http://localhost:3000> with your browser to see the application running.
